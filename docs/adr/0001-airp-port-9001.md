# ADR 0001: AIRP webui 实际端口是 9001,非 5173

## Context

VIBE_CODING.md §3.4 端口分配表写 webui 端口是 5173,但实际启动 `node serve.js` 后监听 9001。需要在 SKILL.md 修正并记录原因。

## Decision

**AIRP webui 实际端口 = 9001**,由 AIRP monorepo 的 `webui/serve.js` 硬编码。

**修正 SKILL.md 端口表**,标注"VIBE_CODING 写 5173 错误"。

## Consequences

- ✅ 与实际服务行为一致
- ✅ 未来 session 不会因为端口错误卡住
- ⚠️ VIBE_CODING.md §3.4 端口表未更新 (其他端口 8000/3001 已验证正确,只有 5173 错误)
- 📌 未来所有引用 webui 端口都用 9001

## Status

**Accepted** (2026-07-13, Session #2)
