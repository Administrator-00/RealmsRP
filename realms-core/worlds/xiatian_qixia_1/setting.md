# 仙剑奇侠传一 · 世界观

> 中国古典仙侠世界,以《仙剑奇侠传一》游戏剧情为底,玩家可扮演李逍遥、林月如、赵灵儿,或自创 OC,走遍神州浩土。

## 时代背景

**景天元年**。神州浩土,六界并存(神、魔、仙、妖、人、鬼)。人间正值纷争之世,朝廷腐败,妖魔横行,门派林立。余杭镇、苏州、扬州、蜀山、锁妖塔、白苗族……这些地名,在这片土地上书写了一段段悲欢离合。

## 主要势力

- **蜀山仙剑派** — 天下第一剑修门派,镇守锁妖塔,弟子遍布天下
- **拜月教** — 苗疆邪教,意图水漫神州,信奉拜月教主
- **白苗族** — 苗疆正义部族,与黑苗族对立,守护大地
- **唐家堡** — 江南暗器世家,擅机关术
- **林家堡** — 江南武林世家,林月如出身
- **圣姑** — 隐居南诏的高人,通晓巫术

## 重要地点

| 地点 | 说明 |
|---|---|
| **余杭镇** | 故事起点,临海小镇,盛帆客栈是必经之地 |

| **扬州** | 女飞贼巢穴,夜探古墓 |
| **京城** | 大梁国都,皇宫巍峨 |
| **蜀山** | 仙剑派总部,云海之上 |
| **锁妖塔** | 镇压群妖之地,七层封印 |
| **白苗族** | 苗疆腹地,瘴气丛生 |
| **南诏** | 大理古国,巫术盛行 |

## 核心规则

- 主角不一定是李逍遥——玩家可选任何内置 NPC 或 OC
- 剧情走向自由,但关键节点(锁妖塔、圣姑巢穴、水魔兽)必有回响
- 战斗以回合制 + 物理/法术/技能/物品 四维
- 死亡可触发剧情回档(由玩家决定是否读档)
- 情感线可选:林月如、赵灵儿、阿奴

## 开局提示

默认起点:**景天元年 三月初一 辰时 · 余杭镇盛帆客栈**

玩家可自定义起始时间,但建议从客栈开始,便于自然进入主线。
